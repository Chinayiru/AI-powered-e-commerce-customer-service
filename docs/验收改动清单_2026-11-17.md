### 架构与交付

- **无静态托管**：`java/src/main/resources` 无 `static/`，全仓无 `addResourceHandlers`/`addViewControllers`，无 CORS 配置 → 违反 `BOUNDARY` §13"dist 由 Java 托管，生产不开第二端口"。当前只能靠 Vite 代理跑。
- **双实现漂移**：`ScriptedAgentClient.java`（18KB，在 `main` 生产包）复制了整套 Python 规则引擎（词表/金额/时效各一份），而指标只在 Python 侧测；`agent.mode` 默认 `scripted` 时真实链路不被走。
- **AC 覆盖缺口**：26 个测试全是场景名，无一条按 AC 编号登记。缺：AC03（异常订单）、AC07（迟到响应 12s）、AC12（确认/撤销并发）、AC15（并发建单）、AC23（工具时间线）、AC24（停 Python 降级）。
  建议：加 `docs/AC_TRACE.md`（AC ↔ 测试方法 ↔ 证据），CI 里检查 26 个 AC 全被覆盖。
