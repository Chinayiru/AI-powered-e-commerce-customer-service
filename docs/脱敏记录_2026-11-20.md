# 当前版本凭证与 URL 脱敏（2026-11-20）

基线：`660663b`。扫描当前受 Git 管理的源码、配置、文档及归档文本，未发现常见格式的真实供应商 API Key、私钥或带认证信息的部署 URL。发现可用于演示环境的固定凭证、MySQL 默认密码、浏览器默认令牌和写死的服务目标。

## 处理

- 移除 dev 中固定 HMAC/坐席令牌；dev/mysql/prod 必须注入两把独立随机凭证，测试合成值和脱敏占位符拒绝进入这些环境。
- 移除 MySQL 默认用户名、密码和主机；Agent/Java 工具服务地址由环境变量提供。URL 校验拒绝包含认证信息、查询串、片段和模板 `.invalid` 域名，错误消息不回显 URL。
- 前端不内置坐席令牌；输入框隐藏字符，旧 localStorage 值清除，新值只保留在标签页 sessionStorage。开发代理目标从环境读取，服务端凭证不写入 `VITE_*`。
- 冒烟脚本从环境读取地址与凭证；纠正其直连 Python 时签名身份与请求体用户不一致的问题。
- 文档旧凭证明文替换为脱敏标记；归档中的服务 URL 使用保留域名替换并登记修改前后 SHA-256。历史测试数字及 source-hashes 保留原义。
- 增加 `.env.example`、本机随机配置脚本和忽略规则。私有 `.env` 不提交；同机多终端加载同一份随机配置。
- 新增 CI `Sensitive configuration audit`，检查常见 Key/私钥格式、已移除凭证的指纹、带凭证 URL 与运行配置中的非空凭证默认值；输出仅包含文件、行号和类型。

本机 localhost 示例、公共文档/依赖地址、XML/Maven 命名空间以及明确用于离线测试的合成夹具保留。扫描器是有限模式检查，不构成对所有潜在秘密格式的保证。
